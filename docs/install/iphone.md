# iPhone 安装与使用教程

**iPhone 当前属于实验支持。** iOS 工作流面向 iPhone / iPad 构建，小屏模拟检查不等于 Safari 真机验收。请以实际发行包和 Actions 构建结果为准，当前没有承诺最低可用系统版本。

## 安装与启用

1. 准备已正确签名、允许安装到本机的 SunnyLanguageLab 应用。目前没有 App Store 或 TestFlight 入口，未签名 IPA 不能直接安装。
2. 有 Mac 的开发者按 [iPad 的 Xcode 路线](ipad.md) 生成 iOS 项目，目标设备选自己的 iPhone。应用与扩展目标都要有匹配的签名和标识。
3. 安装后打开宿主应用一次，在系统设置中搜索 Safari → 扩展，开启 Sunny。
4. 在 Safari 网页打开 YouTube 并允许站点访问。YouTube App、微信内置浏览器、iPhone Chrome 都不是此安装路线。
5. 打开有字幕的普通视频，确认原字幕可读，再展开 Sunny 面板。移动页面无字幕时可尝试请求桌面网站，尚不能保证所有页面版本可读取。

签名的设备限制与有效期取决于 Apple 账户和所用方式，本项目不提供共享证书。没有签名条件的用户需要等待正式分发渠道，下载 IPA 并不等于完成安装。

## 小屏怎么用

- 竖屏收起面板看画面，需要练习时展开，长字幕在面板内滚动。
- 点词查词，点按钮揭晓中文，用上一句 / 重播 / 下一句控制进度。
- 查短语先开启「选短语」，再点首尾词并确认，无需精确拖选。
- 横屏可尝试侧边面板，太挤时回竖屏；小屏横屏仍需真机验证。
- 保持网页内播放，系统原生全屏和画中画不会附带网页学习面板。

收藏后尽早导出 JSON。Safari 后台暂停时同步可能延后，回设置页点「立即同步」补齐。云同步需要自己部署，与浏览器账户同步不同。

## 反馈

提供机型、系统版本、移动 / 桌面网页、视频链接、屏幕方向和操作步骤。中文揭晓失败时说明是画面字幕还是字幕列表；公开截图不要包含密钥、同步口令或私人词库。
