# 公开发行流程

## 公开快照

本次重写目录可单独使用 MIT 授权。公开仓库从新的初始提交开始，不把旧仓库、旧 ZIP、原型分支或私人归档历史一起公开。当前版本为 0.6.0 预览版。

1. 运行测试、双包打包、文档与来源状态检查；核对交付清单和第三方许可。
2. 扫描源码、示例、工作流和产物，排除凭据、签名、用户词库、本机依赖与数据库。
3. 将新的筛选快照推入公开仓库。设置 About、教程入口、安全报告功能。
4. 手动运行 Actions，或在版本提交中使用 `[build-ios]` 启动 iOS 编译；确认宿主应用内有 Safari 扩展，包声明支持两种设备。
5. 版本标签构建通过后，先创建草稿预发行版；核对文件、SHA256、签名要求与真实验证范围再发布。
6. 社交文案只使用已存在且可公开访问的仓库 / 发行链接，不把模拟图写成真机截图。

新代码仍需真机测试。iPhone 继续标为实验支持，Mac Safari 无完整安装包时继续写开发者路线。Cloudflare dry-run 不等于部署。
