## 支持边界

- 普通 YouTube 视频必须有可读取字幕；扩展不进行语音转写。网站接口、自动翻译或权限失败时会显示错误，不保证每个视频能提取。
- 不包含 Netflix 适配、Shorts、直播、YouTube App、原生全屏与画中画面板。
- 两个浏览器包都有 ECDICT 离线英汉子集；英文词典与 AI 由按钮主动联网，AI 默认关闭。
- 旧词汇量分级暂不保留，已收藏词可标记。
- 后台暂停时不能保证同步时机，回完整设置立即同步补齐。

## 真机验收

记录机型、系统、浏览器、版本、视频链接、移动 / 桌面网页和屏幕方向，再检查：字幕读取 → 揭晓中文 → 切句 / 重播重新隐藏 → 查词 / 短语 → 收藏 / 删除 → JSON 备份 → 旋转 → 后台恢复。可选测试 AI 和两设备同步。

`tests/fixtures/study.html` 使用固定字幕与假响应，只验证本地交互，不能代替真实站点网络、Safari 权限和设备行为。
