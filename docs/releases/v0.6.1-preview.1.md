这次更新修复 0.6.0 重写后影响学习体验的问题。

- 修复字幕单词悬停白底白字；调整字幕排版，可选轻薄暗底、透明描边或深色底板。
- 收起后只有视频角落的 44px 小太阳；点词查词单独打开词卡，不再自动展开大面板。
- 恢复词汇量分级标记、2500 / 4500 / 6500 / 9000 / 全部基准、三种标记样式和 H 开关。使用有许可的 ECDICT 词频重新实现，等级仅作学习参考。
- 电脑恢复鼠标拖选短语、悬停暂停与揭晓；iPad / iPhone 继续支持点词、首尾词确认。
- 面板内恢复 AI / 同步配置，完整设置和扩展弹窗也有入口。同一安装保留旧数据时，可主动恢复旧 AI 密钥；已有新密钥会保留。

36 项功能测试、五组屏幕尺寸各 32 项交互检查通过。双浏览器包、Worker 构建与 iOS 原生编译已在[同一提交的构建](https://github.com/morangse/SunnyLanguageLab/actions/runs/40885159298)通过；附件直接来自这次构建，并核对版本、词频 / 词库、许可和 iPhone / iPad 设备声明。

Windows / Mac 桌面 Chrome 选择 chrome ZIP；Safari ZIP 为开发资源；iPhone / iPad 选择 unsigned.ipa，仍需自行签名，不能直接安装。Safari 真机效果仍待验证，iPhone 为实验支持。

**升级前导出生词；更新扩展后刷新 YouTube 网页。不要通过卸载旧扩展来更新，以免丢失本机数据。**
