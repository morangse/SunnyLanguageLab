# 生词备份、升级与恢复

**安装更新、卸载、换签名或换设备前，先导出 JSON。** 生词保存在扩展本机存储中，安装目录、应用身份或签名改变后不一定保留原数据。

## 备份

打开 Sunny 的完整设置页，找到生词同步与备份区域，导出 v0.6 JSON。把文件存到自己的文档目录或可信备份位置，文件可能包含原句、视频链接和个人学习记录，不要放进公开仓库。

从 v0.4 升级时，首次读取会迁移旧生词，并在本机保留未经修改的旧数组。若存在旧备份，设置页也能导出它。本机备份会随扩展卸载一起丢失，必须另存成文件。

## 更新

桌面端：导出 → 保留原安装目录 → 用新文件替换 → 在扩展管理页重新加载 → 刷新视频 → 核对生词。

移动端：导出 → 保留原应用标识与签名方式 → 安装更新 → 确认 Safari 扩展仍启用 → 核对生词。换签名环境或标识可能成为另一份安装，不能承诺原词库自动迁移。

## 恢复

在新安装的完整设置页选择导入 JSON。导入只补充当前未收藏的词，不覆盖已有释义，也不会照搬备份中的删除状态。文件上限 10MB / 20,000 条，失败时保留原文件与错误提示。

恢复后先核对几个词，再连接云同步。两台设备都曾离线修改时，先同步，再主动重新收藏需要恢复的词。

## 备份不包含什么

JSON 生词备份不包含 AI API 密钥、个人同步口令或 GitHub token。恢复后需要在本机重新配置连接。云端 D1 和 GitHub 归档也不替代本机的定期文件备份。

删除词条会保留同步删除记录，GitHub 历史也可能保留旧内容；它不是从所有备份与历史中彻底抹除。断开连接只移除本机同步口令，保留本机生词与待同步项，不会清空云端。
