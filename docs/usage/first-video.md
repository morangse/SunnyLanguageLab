# 第一次练习：用五分钟走完整个流程

先选择一段有英文字幕的 YouTube 普通视频。暂停播放，打开 YouTube 原生字幕确认可用，再启用 Sunny。学习语言选英文，翻译语言选中文。没有字幕时，本扩展不会自行听写。

视频角落默认只显示小太阳，点它或按 T 展开字幕、生词、练习、设置；收起后不会留下整条播放浮窗。

## 1. 看懂

保留原文和中文对照，先看一小段。在面板「练习」页控制字幕隐藏与逐句暂停，在完整设置选择两种语言。中文缺失时确认视频是否提供对应字幕；没有时会尝试本站自动翻译，失败会显示提示。

## 2. 跟读

开启逐句暂停，播放一句后跟读，再点「重播」。上下句用按钮切换。桌面快捷键为 A 上一句、S 重播、D 下一句；在文本框输入时不要依赖全局快捷键。移动端使用可点按按钮。

## 3. 先听再看

开启模糊中文，译文保留原来的长度和位置，以高斯模糊遮盖，不显示提示文字。电脑悬停临时清晰，移开重新模糊；点按可切换清晰 / 遮盖。换句、跳转或重播会恢复遮盖，字幕列表也可直接查看其他行。中文没有生成和中文被隐藏是两种情况：没有生成时不会出现可揭晓的内容。

## 4. 查词与短语

两端都直接点词，词卡单独打开。电脑可按住鼠标从首词拖到末词，松开查询；触屏点「选短语」，再点同一句的首词、末词，最后确认查询。滚动字幕不应触发查词。

两个包都含本机英汉词库，未收录词可主动点「英文词典」或「AI 解释」。AI 默认关闭，需要配置服务商、密钥和可用模型，查询可能产生用量费用。

在「练习」或完整设置中选择词汇量基准（2500 / 4500 / 6500 / 9000 / 全部），可用下划线、底色或彩字标记。H 快捷开关；金色表示已收藏。分级基于词频，是学习参考。

面板的「设置」内分为 AI 解释、同步与备份两个页签，可直接配置 Gemini / Claude、个人 Worker 地址和同步口令，也可打开完整设置。同一安装中仍保留的旧 AI 密钥可主动恢复，恢复后核对模型并保存配置以确认访问权限。

## 5. 收藏与备份

在词卡中点收藏，打开「生词」检查该词、原句和来源。完整设置页支持导出 JSON；第一次练习后就导出一份，确认能用文本编辑器打开。

## 遇到问题

先关掉系统原生全屏，保持网页内播放。刷新页面并检查站点权限和原始字幕。Safari 页面仍无法读取时可以尝试请求桌面网站。不要用反复卸载代替排查，以免丢失本机词库。
